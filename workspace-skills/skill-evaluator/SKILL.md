# skill-evaluator

**通用技能质量评估工具**

适用于所有类型的技能评估——K8s 部署、数据库、CI/CD、监控、前端构建等。

---

## 🎯 评估维度

| 维度 | 权重 | 说明 |
|------|------|------|
| **A. 避免跑偏（Anti-Derailment）** | 25% | 安全默认值、危险操作拦截、幂等性、负面指令 |
| **B. 不处理无关任务（Scope Boundary）** | 20% | 明确边界、任务相关性检测、触发词限制 |
| **C. 流程规范性（Workflow Standardization）** | 20% | 线性流程、步骤完整性、参数校验 |
| **D. 异常处理机制（Exception Handling）** | 20% | 错误→诊断→修复链路、Fallback、超时 |
| **E. 可复用性（Generalizability）** | 15% | 参数化程度、硬编码检测、平台无关性 |

---

## 📋 评估检查清单

### 维度 A: 避免跑偏（Anti-Derailment）—— 25%

| 检查项 | 适用类型 | 说明 |
|--------|---------|------|
| 安全默认值 | 全部 | 危险操作默认禁止，需要显式开启 |
| 危险路径/操作黑名单 | 全部 | 明确列出禁止操作（如删除系统文件） |
| 幂等设计 | 全部 | 已存在/已完成则跳过，不重复执行 |
| 负面指令（Negative Instructions） | 全部 | 用"不要做 X"而非"只做 X" |
| 操作范围限定 | 全部 | 明确限定只操作哪类资源（如只修改 /opt/、只操作 K8s） |
| 确认机制 | 全部 | 危险操作需用户显式确认（输入 yes） |

**评分标准（满分 5）：**
- ⭐⭐⭐⭐⭐：6 项全部满足
- ⭐⭐⭐⭐：满足 5 项
- ⭐⭐⭐：满足 4 项
- ⭐⭐：满足 3 项
- ⭐：少于 3 项

---

### 维度 B: 不处理无关任务（Scope Boundary）—— 20%

| 检查项 | 适用类型 | 说明 |
|--------|---------|------|
| 明确声明 Scope | 全部 | 说明"做什么"和"不做什么" |
| 触发关键词限制 | 全部 | 明确限定激活关键词（如"部署"、"上线"） |
| 任务相关性检测 | 全部 | Step 0 检测超出范围的任务并停止 |
| 技能拆分（分离关注点） | 建议 | 大技能拆成小技能（如 install vs deploy vs rollback） |
| 转接指引 | 建议 | 超出范围时告知用户转接到其他技能 |

**评分标准：**
- ⭐⭐⭐⭐⭐：全部满足
- ⭐⭐⭐⭐：满足 4 项
- ⭐⭐⭐：满足 3 项
- ⭐⭐：满足 2 项
- ⭐：少于 2 项

---

### 维度 C: 流程规范性（Workflow Standardization）—— 20%

| 检查项 | 适用类型 | 说明 |
|--------|---------|------|
| 线性流程（Step 0→N） | 全部 | 顺序清晰，每步有明确入口检查 |
| Step 0 环境预检 | 全部 | 执行前确认环境、身份、路径、参数完整性 |
| 参数校验 | 全部 | 必填参数、默认值、类型校验 |
| 具体命令（Specific Commands） | 全部 | 每步给出可直接执行的 bash 命令，减少歧义 |
| 版本参数化 | 全部 | 关键版本号可配置，不硬编码 |
| 步骤完整性 | 全部 | 包含完整流程（初始化→执行→验证→清理） |

**评分标准：**
- ⭐⭐⭐⭐⭐：全部满足
- ⭐⭐⭐⭐：满足 4 项
- ⭐⭐⭐：满足 3 项
- ⭐⭐：满足 2 项
- ⭐：少于 2 项

---

### 维度 D: 异常处理机制（Exception Handling）—— 20%

| 检查项 | 适用类型 | 说明 |
|--------|---------|------|
| 错误诊断链路 | 全部 | 错误现象 → 可能原因 → 排查命令 → 根因确认 → 修复方案 |
| Fallback 方案 | 全部 | 每个失败场景都有 fallback 指引（如 CLI 失败有降级脚本） |
| 超时处理 | 全部 | 关键步骤设置超时（防止无限等待，如"Use a 10 minute timeout"） |
| 幂等设计 | 全部 | 操作可重复执行不产生副作用 |
| 失败状态处理 | 全部 | 操作失败后的清理或回退指引 |
| 重试机制 | 建议 | 瞬时失败支持重试（可配置） |
| 失败记录 | 建议 | 日志记录到文件便于排查 |

**评分标准：**
- ⭐⭐⭐⭐⭐：满足 6-7 项
- ⭐⭐⭐⭐：满足 4-5 项
- ⭐⭐⭐：满足 3 项
- ⭐⭐：满足 2 项
- ⭐：少于 2 项

---

### 维度 E: 可复用性（Generalizability）—— 15%

| 检查项 | 适用类型 | 说明 |
|--------|---------|------|
| 参数化程度 | 全部 | 主机名、路径、端口、版本等均可配置 |
| 硬编码检测 | 全部 | 扫描硬编码的 IP、端口、路径、凭证 |
| 平台无关性 | 建议 | 不依赖特定 OS 或平台（如需标注依赖） |
| 配置与代码分离 | 建议 | 敏感配置不写死在代码中 |
| 环境适配检测 | 建议 | 检测环境差异并提示（如开发 vs 生产） |

**评分标准：**
- ⭐⭐⭐⭐⭐：全部满足
- ⭐⭐⭐⭐：满足 4 项
- ⭐⭐⭐：满足 3 项
- ⭐⭐：满足 2 项
- ⭐：少于 2 项

## 🔢 综合评分计算

```
综合得分 = (A×0.25) + (B×0.20) + (C×0.20) + (D×0.20) + (E×0.15)
```

**评级标准：**

| 综合得分 | 评级 | 说明 |
|----------|------|------|
| 4.5 - 5.0 | ⭐⭐⭐⭐⭐ 优秀 | 可直接使用 |
| 4.0 - 4.4 | ⭐⭐⭐⭐ 良好 | 轻微改进后可使用 |
| 3.0 - 3.9 | ⭐⭐⭐ 一般 | 需要较多改进 |
| 2.0 - 2.9 | ⭐⭐ 较差 | 需要大幅重构 |
| 0 - 1.9 | ⭐ 差 | 不建议使用 |

## 📚 各类型技能专项检查参考

### 通用技能专项检查（全部技能适用）

> 源自 Prompt Engineering 实践中验证有效的技巧，融入技能评估框架：

| 检查项 | 对应维度 | 示例 |
|--------|----------|------|
| 安全默认值 | A. 避免跑偏 | "Always deploy as preview, not production" — 危险操作默认禁止 |
| 具体命令 | C. 流程规范性 | 每步给出可直接执行的 bash 命令 — 减少歧义 |
| 超时提示 | D. 异常处理 | "Use a 10 minute (600000ms) timeout" — 防止无限等待 |
| 降级方案（Fallback） | D. 异常处理 | CLI 失败有 Fallback 降级脚本 — 提供 B 计划 |
| 负面指令 | A. 避免跑偏 | "Do not curl the deployed URL to verify" — 明确禁止不当操作 |

### K8s 部署类技能专项

| 检查项 | 说明 |
|--------|------|
| generate.sh 必须在 apply 前执行 | 防止本地修改被覆盖 |
| 多 ReplicaSet 检测 | 多次 apply 产生多个 RS 导致资源重复计算 |
| 节点内存 vs 组件 limits 之和 | 部署前检查是否超过节点容量 |
| JVM -Xmx vs 容器 memory limit | 避免 OOMKilled |
| readiness/liveness probe 路径可用性 | 避免 probe 失败导致 pod 不 Ready |
| 硬编码中间件地址 | 127.0.0.1/localhost 应通过环境变量覆盖 |
| imagePullSecrets 配置 | 私仓镜像必须配置认证 |

### 数据库类技能专项

| 检查项 | 说明 |
|--------|------|
| 备份必须先于变更 | 任何数据变更前必须有备份方案 |
| 连接凭证不硬编码 | 密码/密钥通过环境变量或 vault 注入 |
| 大表 ALTER 先建索引 | 避免锁表导致服务不可用 |
| 幂等设计 | 重复执行不会重复创建或丢失数据 |
| 事务边界明确 | 长事务拆分成小事务 |
| 连接池配置 | 防止耗尽数据库连接数 |

### CI/CD 类技能专项

| 检查项 | 说明 |
|--------|------|
| secrets 不写入日志 | 敏感信息脱敏 |
| 并行任务资源隔离 | 防止资源竞争 |
| 超时设置 | 防止无限等待 |
| 产物清理 | 避免磁盘占满 |
| 幂等设计 | 重复触发不破坏状态 |
| 环境一致性 | dev/staging/prod 环境差异化处理 |
