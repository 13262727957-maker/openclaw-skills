# api-validator

## 作用

对源码接口文档进行深度校验，补全缺失信息，生成完整接口文档。

## 概况

| 项目 | 说明 |
|------|------|
| 输入 | `source-api-doc.md` + 源码目录 |
| 输出 | 校验报告 + 补全后的接口文档 |
| 校验内容 | 接口存在性、参数完整性、Swagger 交叉验证（可选） |
| 补全内容 | 响应示例、业务逻辑、错误码、调用依赖 |

## 使用方式

```
输入参数：
  SOURCE_API_DOC = "/tmp/api-scan/{项目}/source-api-doc.md"
  SOURCE_CODE = "/tmp/api-scan/{项目}"
  SWAGGER_API_DOC = "可选"  # 有则交叉验证，无则深度补全

输出文件：
  validation-report.md ← 校验结果 + 缺失项清单
  source-api-doc.md   ← 原地补全（追加附录）
```

## 工作流程

1. **Step 0**：环境预检
2. **Step 1**：解析接口文档
3. **Step 2**：深度扫描源码
4. **Step 3**：逐接口校验
5. **Step 4**：Swagger 交叉验证（有 Swagger 时）
6. **Step 5**：补全缺失信息
7. **Step 6**：输出最终报告

## 缺失项清单

| 缺失项 | 优先级 |
|--------|--------|
| 响应示例缺失 | 高 |
| 业务逻辑说明缺失 | 高 |
| 调用依赖关系缺失 | 中 |
| 错误码定义缺失 | 中 |
